## Page Table Translator

---

### 📌 Project Description

This project is a C-based implementation of a Page Table Translator that demonstrates how logical addresses are translated into physical addresses using the paging memory management technique. The program accepts logical addresses from the user, divides each address into a page number and offset, checks the page table to determine whether the required page is currently loaded into physical memory, and calculates the corresponding physical address when possible.
The program also detects page faults and out-of-bounds logical addresses.

### 🎯 Objectives
- Understand the concept of paging in memory management.
- Demonstrate logical address translation.
- Calculate page numbers and offsets from logical addresses.
- Use a page table to map pages to physical frames.
- Calculate physical addresses.
- Detect page faults.
- Detect logical addresses outside the allowed address space.

### 🧠 Key Concepts

The project demonstrates the following operating system concepts:
- Logical Address
- Physical Address
- Paging / Page
- Frame
- Page Table
- Page Number
- Offset
- Page Fault
- Logical Address Space / Physical Memory

### 🎓 Academic Context

This project was developed as a university mini project to demonstrate the concepts of memory management and paging in Operating Systems.
